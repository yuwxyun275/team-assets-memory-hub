# 团队资产渐进式披露

## 当前实现

此链路用于已经通过质量评估并获批发布的 Wiki、Chat Memory、Code Graph、Skill 内容单元。个人资产的原生 Skill/Knowledge 路径不改动。

1. Proxy 从当前用户的授权资产集合召回候选；编排器以索引卡片成本选择资产，而不是因完整正文过大直接淘汰它。
2. 在 Core 持久化“用户、团队、Agent、任务、会话、资产 ID、revision ID”清单。清单独立于客户端聊天历史；每个清单最多保留 64 条引用，30 天后失效并清理。并发更新使用 CAS 合并。
3. Proxy 检查本次实际发送的消息。必须同时找到对应版本和完整正文，才认为内容仍然存在；摘要里的名称、ID、哈希不能替代正文。
4. 正文仍在时不重复追加；正文不在时提供名称、用途、版本和可执行读取命令。完整同一卡片仍在时也不重复追加。卡片消失后可从重新授权、重新推荐的结果恢复，读取所需的会话引用清单仍存储在 Core。
5. 模型通过 CodeBuddy 现有终端工具调用 `/asset-bridge/read`。这是可执行的 curl 读取接口，不是在 `tools` 数组中虚构一个客户端不认识的函数。网关须将此路径路由到 Proxy。
6. Bridge 从已绑定会话取得身份和业务密钥，调用 Core 的 `disclosure-read`。Core 再次检查成员身份、Agent/任务边界、使用权限、会话引用和当前发布版本。返回完整审核正文及其哈希，不返回评审支持材料、任意 URL 或未审核原生容器。

身份密钥不进入卡片或模型上下文。与既有 skill-bridge 一样，会话标识是读取能力的一部分；入口必须处于同一受保护网关/本地可信网络中，不可作为公开匿名读取服务。

## 正文、卡片、压缩

- 短小的 Wiki 业务约束是提前加载的例外：默认不超过 600 字符，且必须在预算内完整放入。不是所有短资产都会自动展开。
- 被压缩掉的长正文默认恢复为卡片，模型确实需要时再取回完整内容。卡片不是“永远不会被压缩”，可靠性来自后台保存与请求时恢复。
- 读取结果仍占用上下文。客户端终端输出截断或再次压缩后，Proxy 不会把残片记作完整正文。此版不自动切片、补片或清除客户端既有重复历史。
- 动态文本只追加到本次请求尾部，不回写先前历史。复用检查基于本次可见消息，而非“以前注入过”的布尔标记。

## 版本边界

读取参数必须为资产 ID 和审核 revision ID；人类可读的 `content_version` 仅供展示。资产新内容重新审核形成新快照，不覆盖旧审核正文。

此改动保留现有保守发布门槛：源资产版本变化、暂停或权限撤销会使旧引用读取失败；不会悄悄返回最新正文。新版本获批并被推荐后，会产生明确的新卡片。此版不把现有发布流程改为“旧发布版持续服务、新草稿并行审核”，也不自动批准新版本。

## 证据与反馈

- `disclosure-remember`：保存候选引用，不证明正文已进入模型上下文。
- `disclosure-read`：保存只读访问记录，表示接口已返回正文，不证明模型已采用。
- 后续实际请求携带完整对应正文，或 Proxy 确实追加完整短正文时，才登记正文 exposure，并继续使用既有后续会话评估流程。
- 不把卡片展示、读取成功、助手自称采用当作有效贡献；后续效果分仍由有依据的评估产生。

## 配置与失败处理

`injection.teamAssets.progressiveDisclosure` 默认 `true`，总开关仍由 `injection.enabled`、injectors 中的 `team-assets` 和 `teamAssets.enabled` 控制。

- `inlineMaxChars: 600`：短 Wiki 提前加载上限；设为 0 表示全部先给卡片。
- `readMaxChars: 60000`：单份正文读取上限，超限报错，不悄悄截断。大资产应发布为有清晰边界、独立审核的较小内容单元。
- `tokenBudget`：新资产上下文的估算预算，采用 UTF-8 字节数估算，不是上游 tokenizer 的精确计数。卡片或附加验收提示放不下时省略，不截断正文。
- `injection.externalGatewayUrl`：终端能够访问的固定 Proxy 网关；本地未配置时使用 `http://127.0.0.1:<proxy-port>`。远端 CodeBuddy 必须明确配置可达的受保护网关。

Core 或清单持久化不可用时不提供不可读取的新指针，普通 Coding 请求继续。读取失败返回明确错误，禁止把错误当作正文。

## 验证范围

自动化测试覆盖四类正文、持久化恢复、跨身份/会话隔离、权限撤销、旧引用失效、预算错误、卡片去重、完整正文去重、压缩后恢复，以及 OpenAI/Anthropic 实际消息序列化。前缀保持不变不等于已测得生产缓存命中率提高。

本地真实接口联调只验证 Core、Proxy、编排器和持久化链路，不把合成请求/测试判定器报告为真实模型效果、真实 CodeBuddy 任务成功或贡献提升。
