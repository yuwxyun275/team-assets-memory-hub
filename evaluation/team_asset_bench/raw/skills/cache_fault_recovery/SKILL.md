# 缓存故障与恢复回归检查流程

这是经过 QA/SRE 审核的缓存降级验证流程：

1. 先运行正常缓存命中和未命中测试。
2. 在读取前注入 `CacheUnavailable` 故障。
3. 分别验证同租户已发布数据回退、跨租户隔离和草稿阻断。
4. 验证每次请求只读取 Redis 一次，避免形成重试风暴。
5. 恢复 Redis，验证下一次读取重新命中缓存且不访问数据库。
6. 在同一次运行中执行完整的公开测试和隐藏回归测试。

只有故障路径和恢复路径在同一次测试中全部通过，才能判定该流程验证成功。
